# Sistema de Correção de Trabalhos

Aplicação Python local para criar templates de correção, registrar avaliações de Fase 1 e Fase 2 e gerar relatórios textuais.

## Como rodar

```powershell
python app.py
```

Depois acesse:

```text
http://127.0.0.1:8000
```

Os templates ficam salvos em `templates.json`.

Cada correção fica em um arquivo próprio dentro da pasta `corrections/`.
